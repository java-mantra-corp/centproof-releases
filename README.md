# CentProof Releases

Signed and notarized macOS release binaries for [CentProof](https://centproof.com).

This repository hosts the `.dmg` and auto-updater artifacts that CentProof's
in-app updater fetches. Source code is maintained in a separate private
repository.

To download the latest version of CentProof, visit
<https://centproof.com/download>.

## Releases

See the **Releases** tab for all versions, signed with our Apple Developer
ID and notarized by Apple.
